# 给 Codex 主人的中文快速开始

## 这是什么

让你自己的 **Codex App / CLI** 通过 **Magpie** 使用你**合法有权访问的** CodeBuddy iOA 模型：

`Codex → Magpie（3425）→ 本地 SDK Bridge（8791）→ CodeBuddy 官方 SDK（ioa）`。

**限制**：Skill 不能自动领取企业 iOA Key、增加 AI TOKEN 额度，不能保证所有账号都支持 `gpt-6-astra`。需要你自己授权下载代码、访问公司模型、执行测试及设置应用。当前函数调用是在模型 Prompt 里模拟 JSON 工具调用，再转换为 Codex 真正执行的工具，不是 SDK 原生 MCP。

## 安装 Skill

把 `codebuddy-ioa-codex` 文件夹放进 `~/.agents/skills/`，确保路径是：

`~/.agents/skills/codebuddy-ioa-codex/SKILL.md`

或者在 Codex 中让 `$skill-installer` 安装公开的 GitHub 路径：

`https://github.com/ReyJerry/codebuddy2api/tree/codex-skill-v1/.agents/skills/codebuddy-ioa-codex`

然后让 Codex 执行：`$codebuddy-ioa-codex 帮我排查并搭建合法的 iOA → Magpie → Codex 接入，不要让我在聊天中粘贴任何密钥。`

## 主人可在本机终端执行的命令

```bash
SKILL_DIR="$HOME/.agents/skills/codebuddy-ioa-codex"
python3 "$SKILL_DIR/scripts/bridge_setup.py" doctor
# 授权后：
python3 "$SKILL_DIR/scripts/bridge_setup.py" install
python3 "$SKILL_DIR/scripts/bridge_setup.py" init-key
python3 "$SKILL_DIR/scripts/bridge_setup.py" start --experimental-tools
```

`start` 会让你在自己的终端输入官方 iOA API Key，输入时不会回显；不把它发给 Codex 聊天。这里的本地 key 是另一个密钥，用于 Magpie 连接本地 Bridge。桥接服务要持续运行；按 `Ctrl+C` 停止。

另开终端：

```bash
python3 "$SKILL_DIR/scripts/bridge_setup.py" probe
python3 "$SKILL_DIR/scripts/bridge_setup.py" magpie
python3 "$SKILL_DIR/scripts/bridge_setup.py" copy-key
```

`probe` 默认只查询本地健康和模型列表，不请求收费推理。如果你授权实际推理：

```bash
python3 "$SKILL_DIR/scripts/bridge_setup.py" probe --model 你自己已获授权的模型ID --invoke --accept-charges
```

**Magpie**：添加自定义供应商，在 **OpenAI Responses** 填写 `http://127.0.0.1:8791/v1`，把「OpenAI 兼容 / Chat Completions」的地址留空；API Key 粘贴本地 key（不是腾讯官方 key）；模型 ID 用 `probe` 列表中且实际有调用权限的值。然后在 Agents → Codex 选择此模型，重新打开 Codex App 会话。

最后在独立的临时工作区做 `pwd`、`apply_patch` 和 unittest 三轮测试，真实结果要以工具调用记录、退出码和 stdout/stderr 为依据。完整的失败→修复→扩展验证见 `e2e-tests.md`。

## 遇到错误

- 404：大概率路由配置错误，Magpie 需选 **OpenAI Responses**。
- 401：8791 服务与 Magpie 使用的**本地** key 不同。
- 413：实际 HTTP/Prompt/工具 Schema 容量超限，不是所有模型都能接收无限上下文。
- 422：检查是否还是旧版 64 工具限制、工具协议不支持，或实验工具未开。
- 502：检查 SDK、模型授权和结构化工具响应；不要自动重复发起可能付费的请求。

任何修改都不需要删除你以前的 `codebuddy2api` 文件夹或它的 `.env` / `auth/`。完整故障表见 `troubleshooting.md`。
